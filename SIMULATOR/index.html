Forensic & Compression Methodology

Empirical reverse-engineering & visual distortion analysis
1. Empirical Transcoding Matrix

2. Mobile Phone Camera Orientation Correction

Smartphone cameras (iPhone, Samsung, Pixel) record the raw CMOS sensor matrix in landscape orientation, appending an EXIF metadata tag (Orientation = 6) when captured vertically in portrait. When uploaded, the simulator executes ImageOps.exif_transpose() prior to downsampling, guaranteeing that both the original display and the simulated output remain in perfect upright spatial alignment.

3. Inferno Difference Heatmap Algorithm

Compression artifacts (such as high-frequency blocking, ringing, and color degradation) are often imperceptible to the human eye. We compute the per-pixel mean L1 color distance between the original and transcoded image:

diff(x, y) = (|R_orig - R_comp| + |G_orig - G_comp| + |B_orig - B_comp|) / 3
boosted(x, y) = [ (diff / 255.0) ^ 0.65 ] × 255.0 × 2.8

The boosted values are mapped through the 256-color Inferno colormap (Dark Violet → Indigo → Crimson → Orange → Bright Yellow), highlighting subtle DCT boundaries and edge artifacts.

4. Visual Distortion Scale
Minimal (< 2.0) Near-identical perceptual fidelity to the source image.
Low (2.0 – 5.0) Very minor attenuation of ultra-fine high-frequency textures.
Moderate (5.0 – 12.0) Noticeable softening around sharp contours and high-contrast edges.
High (> 12.0) Evident compression blocking, color quantization, or heavy downscaling.

About Platform Compression Simulator

🎯 The Forensic Challenge

Modern deepfake detection models (including TruFor, Noiseprint++, and PRNU sensor extraction) achieve up to 94.9% ROC-AUC on clean, uncompressed camera sensor images. However, when images are transmitted across social media networks, aggressive transcoding pipelines destroy high-frequency noise fingerprints, dropping model accuracy down to 57%–81%.

⚡ What This Simulator Solves
Real-Time Cross-Platform Simulation: Instantly visualize how any photo looks after being compressed by WhatsApp, Instagram, Facebook, or Telegram without uploading to live accounts.
Forensic Difference Detection: Uses a non-linear amplified Inferno colormap to expose invisible compression noise, ringing artifacts, and downscaling alterations.
Automated Batch Dataset Pipeline: Compress thousands of benchmark images automatically to generate realistic training datasets for robust, real-world deepfake detectors.
🛠️ Technical Architecture

Engineered with zero-dependency vanilla technologies for speed, reliability, and precision:

  • Backend Core: Python 3 Flask microservice, Pillow (PIL), NumPy array computation.
  • Transcoding Engines: Exact 64-element DCT DQT injection (WhatsApp, Facebook, Telegram) and native WebP VP8 compression (Instagram).
  • Smart Pre-processing: Automated EXIF rotation normalization and transparent PNG alpha-compositing.
  • Frontend UI: Pure HTML5, modern CSS3 (Apple/Vercel aesthetic), and vanilla ES6 JavaScript.
